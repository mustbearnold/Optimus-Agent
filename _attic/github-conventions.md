# Historical GitHub conventions

This repository no longer uses GitHub issues, pull requests, labels, or `gh` for
development workflow or delivery. This file remains as a tombstone so older
ADRs and plans have a stable link and coding agents do not rediscover the former
process as current policy.

Do not execute older instructions referring to `wip/*`, `pr/<N>-*`, PR labels,
issue triage, `github_pr_branch.py`, `sync-github-labels.py`, or `gh`. Root
[`AGENTS.md`](../../AGENTS.md) is the only current VCS and delivery authority.

Historical Git commits and ADRs retain their original wording as evidence of the
superseded process.
