# Evidence guide

Evidence is bound to its named candidate, environment, method, and date. It can
support or falsify a current claim, but it never becomes a standing product
instruction or roadmap merely because a run passed.

Use the [generated catalog](../CATALOG.md#evidence) to browse evidence records.
For current product truth, return to [Optimus Agent today](../current/status.md).
