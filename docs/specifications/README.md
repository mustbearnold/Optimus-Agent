# Specifications

Specifications describe a bounded behaviour or acceptance contract. Their
frontmatter decides whether they are current truth, planned work, or history;
the directory name alone grants no authority.

Use `just docs-search "<intent>"` for current/default retrieval, or consult the
[generated catalog](../CATALOG.md) to inspect all lifecycle planes. The
[Synthetic User Lab](synthetic-user-lab.md) is the canonical harness-testing
specification.
