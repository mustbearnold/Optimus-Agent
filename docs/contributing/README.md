# Contributing to Optimus Agent

The repository is developed autonomously through isolated worktrees and the
managed delivery commands. Start with [AGENTS.md](../../AGENTS.md), then use:

- [Managed delivery](managed-delivery.md)
- [Artifact naming](artifact-naming.md)
- [Project hygiene](project-hygiene.md)

[GitHub conventions](github-conventions.md) are preserved historical process
context. They do not override the current managed-delivery law.
