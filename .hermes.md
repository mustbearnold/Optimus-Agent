# Optimus Agent — Hermes Rules

## Disk hygiene

- **Clean `target/` after every significant build cycle** unless you're actively iterating. 21 GB of debug artifacts accumulate fast.
- **Do NOT create large build artifacts in `local/tmp/`** — that dir is for evidence, baselines, and small config files only. If you need a sandbox target directory, put it outside the repo (`/tmp/optimus-target-*` or similar).
- **Run after any build-heavy task:**
  ```
  cargo clean
  ```
  Or at minimum:
  ```
  du -sh target/ local/
  ```
  and raise a warning if either exceeds 2 GB.
- If `local/` grows beyond 500 MB or `target/` beyond 5 GB of actual iterative work, warn the user.

## What `local/` is for

- Test evidence (screenshots, reports)
- Baseline configs
- Spike outputs smaller than 50 MB each
- **NOT** for `cargo-target/`, `detached-*`, `leptos-target/`, or any rebuildable Rust build artifacts
